## Project Overview

This is a React + TypeScript visualization project that displays Bitcoin UTXO (Unspent Transaction Output) Realized Price Distribution data from Glassnode. The application shows day-over-day changes in how Bitcoin is distributed across different price ranges, helping identify capital flows and holder behavior.

## Data Pipeline Architecture

The project has a two-stage data processing pipeline:

### 1. Raw Data Collection (`glassnode_utxo_data.json`)
- Manual data extraction from Glassnode Studio API endpoint: `utxo_realized_price_distribution_ath`
- Contains historical snapshots with fields:
  - `t`: Unix timestamp
  - `ath_price`: All-time high BTC price
  - `current_price`: Current BTC price at snapshot time
  - `total_supply`: Total Bitcoin supply
  - `partitions`: Array of BTC amounts in each price bucket (100 buckets)
  - `prices`: Array of price boundaries in USD corresponding to partitions

### 2. Processed Data (`public/distribution_changes.json`)
- Generated by `calculate_distribution_changes.py`
- Calculates day-over-day changes in UTXO distribution across price ranges
- The algorithm handles dynamic price buckets by accumulating yesterday's values up to today's price boundaries
- Only the last 1750 data points are processed to keep file sizes manageable
- Output format:
  - `date`: Date string (YYYY-MM-DD)
  - `total`: Net daily change in BTC (mostly from mining)
  - `prices`: Price bucket boundaries
  - `changes`: Array of BTC amount changes per price bucket

**Critical Implementation Detail**: The change calculation (lines 30-42 in calculate_distribution_changes.py) uses a cumulative approach because price buckets can shift between days. For each of today's price points, it sums all yesterday's values up to that price, ensuring apples-to-apples comparison even when bucket boundaries change.

## Data Update Workflow

To update the visualization with latest Glassnode data:

1. Navigate to https://studio.glassnode.com/charts/indicators.UtxoRealizedPriceDistributionAth?a=BTC&mScl=lin&pScl=lin&resolution=24h&zoom=all
2. Open browser DevTools Network tab and find the API response
3. Copy the JSON response and replace contents of `glassnode_utxo_data.json`
4. Run: `python calculate_distribution_changes.py`
5. Verify output shows successful conversion
6. Commit with message: "new data - [latest date]"
7. Push to main (triggers CI/CD deployment)

## Tech Stack

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite 5
- **Styling**: TailwindCSS
- **Charts**: Recharts (specifically using BarChart with color-coded cells)
- **Data Processing**: Python 3 (single script, no external dependencies)

## Component Architecture

The app has a simple single-component structure:
- `App.tsx`: Root component with minimal layout
- `UTXODistributionChart.tsx`: Main visualization component that:
  - Fetches `/distribution_changes.json` on mount
  - Provides date selector dropdown
  - Renders interactive bar chart showing distribution changes
  - Color codes bars: green for increases, red for decreases in each price range
  - Custom tooltip shows detailed metrics for each price bucket

## Key Files

- `src/components/UTXODistributionChart.tsx:24` - Data loading logic
- `src/components/UTXODistributionChart.tsx:44-69` - Chart data transformation
- `calculate_distribution_changes.py:30-42` - Core distribution change algorithm
- `glassnode_utxo_data.json` - Raw data source (19MB+, tracked in git)
- `public/distribution_changes.json` - Processed data consumed by frontend

## Important Notes

- The JSON data files are large and tracked in git (no gitignore for them)
- The chart shows 100 price buckets, but only displays every 5th label to avoid overcrowding
- Distribution changes can be negative (BTC moved out of price range) or positive (BTC moved in)
- Total daily change is typically small and positive due to new mining supply
- When modifying the Python script, ensure the cumulative bucketing logic is preserved to handle dynamic price boundaries correctly
